# RescuePath AI — brand assets

A shield (protection) with a road (the evacuation route) leading to a map pin (the safe point). The sparkles stand for the AI.

| File | Use |
|---|---|
| `rescuepath-logo.svg` / `png/rescuepath-logo.png` | Full logo on light backgrounds |
| `rescuepath-logo-on-dark.svg` / `png/rescuepath-logo-on-dark.png` | Full logo on dark backgrounds |
| `rescuepath-icon.svg` / `png/rescuepath-icon-{1024,512,192}.png` | Icon only (avatars, PWA icons, slides) |
| `rescuepath-icon-on-dark.svg` | Icon only, with a faint outline for dark backgrounds |
| `rescuepath-favicon.svg`, `favicon.ico`, `png/favicon-{16,32}.png` | Simplified icon for 32px and below |
| `png/apple-touch-icon.png` | iOS home-screen icon (180px, white background) |

The text in the logos is converted to outlines, so it looks the same on every machine. The font is **Geist** (ExtraBold 800 for the name, SemiBold 600 for the tagline), the same font the Next.js site uses.

## Colors

| Name | Hex | Used for |
|---|---|---|
| Navy | `#0E2238` | Name text, shield (gradient `#1D4573` → `#0B1B2E`) |
| Safe green | `#2DD4A4` | Map pin, "AI" badge on dark |
| Deep green | `#0FA37F` | "AI" badge on light |
| Amber | `#FFB020` | AI sparkles |
| Slate | `#5B6B7D` / `#9FB3C8` | Tagline on light / dark |

Keep clear space around the logo of at least the height of the "AI" badge. Don't recolor, stretch, or rearrange the parts.
